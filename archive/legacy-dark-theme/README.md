# Legacy dark-theme fork (archived)

This was an earlier design direction for Sina's Creations — a darker, gold-accented
theme with a 39-item sample product catalog. It was never wired into `App.jsx`
(the live app renders `src/pages/SinaPages.jsx` only), so it was archived here
rather than deleted, in case any of its copy, layout ideas, or product descriptions
are worth pulling into the current lifted/cream design system.

Nothing in this folder is imported by the live app. Safe to reference, not safe to
import directly (styling assumes a different set of CSS custom properties than
`src/styles/global.css`).
